# Download instructions

1. Download the public municipal crime datasets from the official portals listed
   in this folder.
2. Place the files under `data/raw/` using these names:
   - `cdmx.csv`
   - `chicago.csv`
   - `london.csv`
3. Run `python scripts/00_check_environment.py`.
4. Run the stage scripts in numeric order.

The public release includes artifact-level reproduction assets. Full raw-data
reproduction requires the raw public datasets, which are not redistributed due
to size, provenance, and source-license boundaries.
